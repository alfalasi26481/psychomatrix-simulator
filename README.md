## Leadership Test Ability — `/lta/`

تطبيق مستقل متخصص في **الحكم على المواقف القيادية**.

**المحتوى**
- **١٢٠ موقفًا قياديًا** على أربعة مستويات (قيادة الفريق المباشر، الإدارة عبر
  الأقسام، القيادة التنفيذية، المعضلات والأزمات) — ٣٠ موقفًا لكل مستوى.
- **٤٨٠ ردًّا** لكل منها تقدير لجنة خبراء مُسوَّغ على سلّم الفعالية الرباعي،
  و**نمط سلوكي** من اثني عشر نمطًا (معالجة الجذر، تحقّق قبل الحكم، رفع للجهة
  المختصة، نقل القرار، تأجيل، تجنّب مواجهة، تجاوز صلاحية، قرار بلا تحقّق،
  إرضاء الأطراف، توثيق بلا معالجة، حسم فوري، معالجة العَرَض).

**التدريب**
- **جميع الأقسام مفتوحة** — لا قفل بين مستوى وآخر ولا شرط تسلسل.
- سبعة أوضاع: تدريب موجَّه · محاكاة بميزانية ٩٠ ثانية للموقف لا تُعاد ·
  جولة سريعة · اختبار شامل (١٦ موقفًا / ٢٤ دقيقة) · جولة نقاط الضعف ·
  المراجعة المستحقة · جولة علاجية على كفاية بعينها.
- **تكرار متباعد**: الموقف المُتقن يبتعد (١ ← ٣ ← ٧ ← ١٤ ← ٣٠ ← ٦٠ يومًا)
  والمتعثّر يعود غدًا.
- **خطة تدريب ١٤ يومًا** وسلسلة أيام متتالية.

**التقرير**
- الدرجة وخريطة رادار للكفايات الثماني ومسار الجولة.
- **تحليل الإيقاع**: زمن كل موقف مقابل دقّته، المواقف المستعجلة والمستنزِفة،
  ومنحنى الإرهاق بين نصفَي الجولة.
- **أنماط الردّ**: أيّ نوع من الحلول يغريك، بمقارنة تقديرك بتقدير اللجنة لكل نمط.
- **معايرة الثقة**: هل تعرف متى تكون مخطئًا.
- أربعة مؤشرات لنمط الحكم، وخطوات علاج مرتّبة بالأثر تبدأ جولة بضغطة.

**المنصّة**
- مكتبة مرجعية مفتوحة للمواقف الـ١٢٠ مع حفظ وملاحظات شخصية.
- ملفات متعددة على الجهاز نفسه، وتصدير/استيراد التقدّم.
- تعمل دون اتصال (PWA)، وتُثبَّت على أندرويد وآيفون وسطح المكتب.
